Js:
JavaScript (JS) is a high-level, interpreted programming language used to make websites interactive and dynamic. 
It allows developers to handle events, validate forms, manipulate HTML and CSS, fetch API data, perform calculations, and build modern web 
applications using functions, objects, arrays, and asynchronous programming.

React:
React is a JavaScript library used to build fast, interactive, and dynamic user interfaces. 
It allows developers to create reusable components, manage application state, handle events, and build single-page applications efficiently 
using JSX, props, hooks, and virtual DOM.
